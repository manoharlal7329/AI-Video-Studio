# FFmpeg Specifications

## 1. Ken Burns Effect (Zoom/Pan)
To make static images (from Pollinations AI) look dynamic, we use the `zoompan` filter.
**Example Flag**: 
`-vf "zoompan=z='min(zoom+0.0015,1.5)':d=125"`
*(Slowly zooms in on the image over its duration)*

## 2. Image & Audio Merge
Combining the synthesized TTS (Piper) audio with the generated image to create a single scene video.
**Command**:
```bash
ffmpeg -loop 1 -i scene_image.jpg -i scene_audio.wav -c:v libx264 -c:a aac -b:a 192k -pix_fmt yuv420p -shortest scene_output.mp4
```

## 3. Subtitles Integration
Burning subtitles into the final video using the `.srt` generated by Whisper.cpp.
**Example Flag**: 
`-vf subtitles=assets/subtitles.srt:force_style='FontSize=24,PrimaryColour=&H00FFFFFF'`

## 4. Final Scene Stitching
Stitching multiple scene MP4s together, optionally with crossfade transitions.
**Command** (Basic Concat):
We will use a `concat.txt` file listing all scene files.
```bash
ffmpeg -f concat -safe 0 -i concat.txt -c copy final_stitched.mp4
```
**Command** (With Crossfade):
```bash
ffmpeg -i scene1.mp4 -i scene2.mp4 -filter_complex "[0:v][1:v]xfade=transition=fade:duration=1:offset=4[v]" -map "[v]" final_output.mp4
```
